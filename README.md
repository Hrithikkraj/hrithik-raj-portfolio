# Hrithik Raj Portfolio

Personal portfolio website for Hrithik Raj, built with React, TypeScript, and SCSS.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.

## Build for production

```bash
npm run build
```
